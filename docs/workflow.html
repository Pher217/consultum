Opus drives. Workers type. The channel opens when they’re stuck.

An orchestrator delegates clear specs to cheap middle-tier workers and verifies every result. The novel part — workers can’t normally consult each other, so any worker can open a channel upward: a curator compresses its problem into clean evidence, and a stronger advisor answers. Read-only. The orchestrator still decides.

Any engine can open the channel: a Claude worker via a subagent, a Codex worker via claude -p, an Ollama worker via the consult_advisor tool. Sensitive work stays first-party or local — the channel is fail-closed and never sends secrets to a third party.
